Badges, tags and status

A count is a number. A tag labels content. A status chip says the state of a thing, always with a word, never colour alone.

Badges, tags and status

Do
  • Pair every status colour with a word, such as "Failed".
  • Use a count only for a number.
Don't
  • Show a count of 0; hide the badge.
  • Use the lime tag for anything but new content.
