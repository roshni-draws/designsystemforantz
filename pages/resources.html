Resources

Downloads

The files behind this site: tokens, components, the colour JSON and the tools that check them.

Files

colors.json
Every colour token, light and dark, in the W3C design-tokens format.
tokens.css
Primitives and semantic tokens with light and dark themes.
components.css
Every component class. Uses tokens only.
README
How to use the files, where the values came from, open questions.
tools/colors.py
Builds and checks colors.json and the contrast table.
Docs site files
assets/site.css and assets/site.js run this site; they are not part of the system.

Run it locally

cd design-system-foundation && python3 -m http.server 8092
# then open http://localhost:8092/

Downloads

Do
  • Feed colors.json to design tools and code generators.
  • Regenerate it with tools/colors.py after changing a colour token.
Don't
  • Edit colors.json by hand; it is generated.
  • Copy hex values from it into components; use the CSS variables.
