Attachments

A drop area to add files, then a grid of tiles. Each file type has its own hue, so a list of mixed files reads at a glance. A tile can show upload progress and a remove button.

Attachments

Do
  • Show the file type as an extension label as well as a colour.
  • Name the file in every remove button's label.
Don't
  • Show an upload as done before it finishes.
  • Accept a file without stating the size limit first.
