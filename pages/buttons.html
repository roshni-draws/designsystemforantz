Buttons

One primary button per view or card. Buttons say what happens, as a verb: "Approve", "Send invite".

  1. Container, 42px high (34 small, 48 large), 10px corners
  2. Optional leading icon, 18px
  3. Label, 14px semibold, sentence case

Button tones and FAB

Two new fills, tint and line, take any accent hue through --c. Set --c to an -ink token so the label passes AA in both themes. Info and warning fill like danger does.

Buttons

Do
  • Pair Approve (primary) with Edit (outline) and Decline (ghost).
  • Give every icon button an aria-label.
Don't
  • Put two primary buttons side by side.
  • Use danger for "Decline": it is not destructive.

Button tones and FAB

Do
  • Use one FAB per screen, for the main thing people add there.
  • Use tint and line for secondary actions that belong to a category, such as a teal "Call keeper".
Don't
  • Set --c to a bright hue like --hue-teal: its text fails AA on white.
  • Use the gradient button next to a primary button.
