Colour

Two layers. Primitives (--green-700) are the raw palette and never go in components. Semantic tokens (--color-surface-raised) say what a colour is for and switch with the theme.

A categorical set for avatars, icon tiles and chart series. Each hue has a -soft fill and an -ink text colour. Taken from Style 6's widget hues.

Primitives

Colour

Do
  • Use semantic tokens in components so dark mode works for free.
  • Keep cards white and put colour in the icon tile.
  • Use --color-accent-bright (lime) as a fill: bars, tags, highlights.
Don't
  • Put lime (#52F990) or coral (#FA6140) text on white. Both fail AA.
  • Use Style 6's grey #7A8684 for text. It is 3.8:1; use --color-text-muted.
  • Mix more than one strong colour in one card.

Colour

Use semantic tokens in your CSS; the theme switches them for you.

.my-card {
  color: var(--color-text);
  background: var(--color-surface);
  border: 1px solid var(--color-border);
}
.my-tag { color: var(--hue-teal-ink); background: var(--hue-teal-soft); }

colors.json

Every colour token, light and dark, in the W3C design-tokens format. Download colors.json

{
  "light": { "surface": { "color-surface": {
    "$type": "color", "$value": "#FFFFFF",
    "$description": "Cards, header, panels" } } }
}
