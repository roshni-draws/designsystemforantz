Layout and breakpoints

Style 6 is an app frame: an 18px gutter, a white header bar, the main canvas and a 380px right panel, all at 22px corners. Three sizes: mobile, tablet and desktop. They replace Style 6's 640 / 760 / 1060 steps with 600 and 1024, which line up with phones, tablets held either way, and laptops. CSS variables can't go in media queries, so the --bp-* tokens document the numbers; use the numbers directly. Screens are previewed at 390 × 844, 820 × 1180, 1180 × 820 and 1440 × 900.

SizeWidthTokenWhat changes
Mobile< 600px--bp-tablet is where it endsOne column. Bottom tab bar. Docs: the navigation opens as a drawer. Dialogs become bottom sheets.
Tablet portrait600–1023px--bp-tabletApps: 88px side rail, two-column card grids; forms and side panels stack. Docs: navigation drawer.
Tablet landscape, desktop≥ 1024px--bp-desktopApps: 228px rail with labels beside icons, main and aside side by side, three card columns. Docs: the left navigation is always shown.
Wide≥ 1280px--bp-wideAsides widen (2 : 1); docs show "On this page".
